# R1 major 1: the same data for curation and validation

The Sjöberg batch data were the reference during curation; the 13C fluxes, the chemostat growth data and the deletion strains were not. No separate simulation is needed: the results of `../r1_major3_attribution` (`repro`) are reported per data set, with Sjöberg (Figure 1, used during curation) apart from the others (Figure 3, independent). The deletion strains of `../r2_major1_deletions` are the further independent test.
