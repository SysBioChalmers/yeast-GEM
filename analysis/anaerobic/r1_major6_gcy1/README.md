# R1 major 6: Gcy1

`gcy1_thermodynamics.py` computes the reaction energy of glycerol + NADP+ = dihydroxyacetone + NADPH (eQuilibrator, pH 7.2, ionic strength 0.25 M, pMg 3) and the largest dihydroxyacetone to glycerol ratio at which the oxidative direction can run for a cytosolic NADPH/NADP+ ratio of 16 to 22. The effect of making Gcy1 reversible on the predictions is `vdev_new+gcy1rev` in `../r1_major3_attribution` (`sectionB`).
